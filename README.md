# CSYM030-Mobile-Device-Software-Development
StayNest mobile app is a property rental service that aims at matching property owners (hosts) with users requiring short-term accommodation (guests). 
The system helps hosts to design and maintain listings concerning properties by adding details like pricing, availability, and amenities.
The visitors can use a list to view what is available, filter, place a booking order, and/or leave a comment after they have stayed.
Moreover, there is a dispute moderation system that ensures that conflicts between users are addressed to maintain integrity in the system.
StayNest aims to offer a comprehensive and effective online platform to manage short-term rentals. 
It will focus on streamlining the experiences of both hosts and guests by providing a centralized service through which listing, booking, and user activities can be conducted smoothly in real-time.
